# Project 98 — The Last User

An interactive Windows 98-inspired desktop mystery built with React, TypeScript and Vite.

## Included in this build

- Windows 98-style desktop, Start menu, taskbar, window manager and login sequence.
- Shared virtual C: and write-protected D: filesystems with LocalStorage persistence.
- File Explorer with navigation, views, sorting, selection, copy/paste, rename and Recycle Bin operations.
- Working Notepad with open/save/save-as against the shared virtual filesystem.
- Internet Explorer 5-inspired offline browser with local archived pages, Favorites, history and local search results.
- Playable Minesweeper with Beginner, Intermediate and Expert boards, timer, flags and win/loss states.
- Image Viewer for the included fictional archive photographs.
- A populated Classified folder with fictional project records, correspondence, personal notes and photographs.

All intelligence programme and operation names, records and characters in this experience are fictional. Internet Explorer uses local simulated pages and does not connect to the public internet.

## Run locally

```bash
npm install
npm test
npm run build
npm run dev
```
